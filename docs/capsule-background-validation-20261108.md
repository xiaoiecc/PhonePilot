## 本次范围

- 重做相关悬浮控件的表面、图标、配色、信息层级和过渡动画，主 Chat 及其余导航不重设计。
- 运行胶囊、暂停输入、等待提前结束、确认、接管、选择和文字问答，共用现有任务状态投影。
- 输入从一行随实际折行长高，上限六行及可用高度，之后滚动；发送被接受才清空，暂停发送可继续同一会话。
- 同一任务前后台迁移，运行中的任务成功切换后继续，已有或新发出的暂停/停止/交互不丢失。
- 模型 function 每次调用必须携带中途说明，整体动作 batch 一句；正常气泡和详细轨迹保留。
- 新增无障碍四方向滚动、目标显示屏隔离，保留动态列表 `click_match` 的完整身份与拒绝规则。

## 架构集成

唯一协调器管理生命周期、迁移命令、迁移 Job 和设备互斥门禁。所有设备操作与位置迁移在门禁中串行，UI 只发命令和读投影。显示会话后端拥有 VirtualDisplay、ImageReader、任务 Token 与租约，不拥有第二个任务生命周期。

请求、观察、截图和节点都关联位置代次。模型请求中途或两轮之间发生迁移时，旧工具调用得到未执行回执，重新观察后生成新动作；已执行结果保留，不重放。在真实任务日志中观察到两次因位置变化而跳过的调用。

后台截图接入既有单飞 Binder 截止、分块读取、临时文件清理及 WebP 编码链，没有另起任意脚本截图入口。后台无障碍没有主屏回退；文字输入核对编辑器包名与系统报告的输入目标显示屏，未知时拒绝提交。

## 发现并修复的问题

- 运行下一步清空当前说明，使胶囊退回无信息的“执行中”：保留最新说明直至替换，新任务才清空；核心回归通过。胶囊最多两行，独立箭头展开全文和历史，前后台共用实时状态。
- 首击编辑器可能早于窗口获焦而请求 IME：改为真实窗口焦点监听与带代次的一次请求，取消/隐藏/分离时清理回调。最终包的空闲浮窗实机首击确认 `mInputShown=true`；BACK 后为 false，没有穿透导航。暂停/问答复用同一焦点入口，未在修复后再新建模型任务重复验证全部状态。
- framework ImageButton 在 Service inflater 下不采用 app:tint：改为明确的 AppCompatImageButton，并以原生渲染验证。
- 测试用计算器没有普通 Launcher 入口，`am` 即使退出码 0 也会在输出中报告未解析 Intent：夹具改用经核对的显式组件和真实任务确认，未以退出码冒充界面已打开。
- EMUI 冻结无前台服务的测试进程：用现有前台服务为测试提供与真实运行一致的生命周期，不修改系统 freezer 或全局后台策略。

## 限制与未验收项

- 后台后端当前只提供实测的 API 31 能力档案；其他 Android 版本继续保留普通前台能力，后台返回不支持，不能宣称覆盖全部 ROM。
- 应用自身的跨任务跳转、受保护页面、系统界面及特殊启动模式仍需逐类验证；不能由计算器测试推出所有 App 都不会抢前台。
- API 31 无信任显示屏的输入法策略会回退主屏。系统不允许把这类显示屏直接改为 LOCAL；当前目标校验防误输入，**不等于主屏和后台有两套独立键盘焦点**。未验证在用户同时使用主屏键盘时仍可独立输入中文；不能宣称已完成这种隔离。
- 完整旋转/进程死亡/系统强杀恢复、所有业务 App 跨任务链路、后台中文输入及所有人工接管控件组合尚未做完实机验收。已有针对性自动化覆盖不能替代这些结果。
- web/code 是服务端托管工具，不接受本地 function 的 commentary 参数；使用真实返回事件和模型消息，不能伪造该字段。
