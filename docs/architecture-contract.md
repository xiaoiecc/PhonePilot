# PhonePilot 架构契约

本文件是持续生效的设计约束，不是某次任务的完成报告。历史验证结果另放专门报告；实现变化必须保持这些边界，或在用户授权的需求变更中明确说明并同步更新。

## 栈与依赖方向

Android App 使用 Kotlin、Activity/Fragment、传统 View/RecyclerView、协程与 StateFlow，Gradle 构建。核心模块为 Kotlin/JVM。

```text
Chat / 浮窗 / 历史界面
  ├─ 命令 → TaskExecutionManager → RunCoordinator (:automation-core)
  └─ 读取 ← 不可变运行投影 / 会话摘要 / 历史时间线

RunCoordinator → AgentRunner 接口
  Android composition root 提供 PhoneAgent (Responses 协议 runner)
    → AndroidToolExecutor
      → ToolCommandDecoder / 全批次预检 / 检查点 / 交互 / 轨迹
      → 无障碍、坐标、键盘、截图等能力后端
        → 类型化 Shizuku IPC 或 Android 平台能力

执行事实 → HistoryManager → 历史文件与截图
历史文件 → ConversationSummary / HistoryTimeline → 只读展示与导出
```

依赖反转通过核心接口完成。核心不引用 Android 实现；界面不获得设备能力。`RuntimeComponents.kt` 是 Android 装配入口，不是第二个协调器。

## 所有权表

| 事实或能力 | 唯一所有者 | 其他模块的权限 |
| --- | --- | --- |
| 任务 Job、生命周期 stage、暂停原因、交互、等待、终结 | RunCoordinator | 发命令、读快照 |
| Responses cursor、协议输入/输出批次、网络会话 | PhoneAgent | 显式恢复、读 ConversationSnapshot |
| 工具命令分派和预检 | AndroidToolExecutor | 后端实现各自叶子能力 |
| 设备 IPC 成败 | CommandResult / DeviceCommandClient | 读取 exitCode、timeout、truncation 等字段 |
| 编辑器代次、InputConnection 编辑与回执 | KeyboardGateway；事务由 TextInputManager 串行管理 | 提交类型化编辑请求 |
| 浮窗显示、最小化、隐藏与暂停显示租约 | OverlayPolicy | 获取/释放租约，读展示投影 |
| 应用级 Shizuku 连接及事件代次 | ShizukuConnectionManager | 读连接状态、请求刷新 |
| 工具操作事实 | 统一执行入口产生的 HistoryToolCall | 历史保存、界面渲染；无执行权限 |
| 会话分组与历史时间线 | ConversationHistory / HistoryTimeline | 读取；不得改变 runner cursor |

## 生命周期与并发不变量

生命周期包含 IDLE、STARTING、RUNNING、PAUSED、WAITING_INTERACTION、CANCELLING、FINALIZING、COMPLETED、FAILED。公开快照是 stage 的投影，不是另一份可独立写入的生命周期。

- 同时最多一个任务所有者；FINALIZING 仍占有任务。
- runner 返回之前完成设备操作清理；协调器完成持久化后才发布终态和一次完成事件。
- 每个任务异步事件、交互回复和等待跳过请求保留身份。旧 runId、交互 ID、加载或连接 generation 均不能修改新状态。
- 人工确认、接管、选择和文字问答共用 PendingInteraction。销毁界面不能自动决定用户答案或丢失等待。
- 草稿暂停不覆盖手动暂停；清空草稿不擅自恢复用户手动暂停。
- 嵌套隐藏租约不互相释放。暂停显示租约可临时覆盖隐藏，但不能越过用户关闭或新任务代次。
- 取消、失败、日志 IO 失败均不能重放已经执行的输入。未完成的工具协议批次不能直接续用 cursor。

## 工具与权限边界

网络 JSON 在协议/命令解码边界处理；同一入口的只读轨迹可以保存有界、不可执行的参数文本。执行后端接收 sealed command、枚举、验证过的数值及目标引用，不读取任意操作字符串或 JSON 参数包。整个批次预检完成后才开始副作用。

普通进程调用使用 argv。App 名称从可启动应用目录解析；包名/组件名须验证。截图/手势中不可避免的脚本留在私有后端，输入仅限程序生成并验证的值，不暴露“任意 shell”工具。

输入、截图、无障碍节点都有各自生命周期约束。不能因某条工具路径不方便就绕过目标校验、输入回执、无障碍节点租约、截图单飞或截止时间。BACK 是一次 Android BACK，ESCAPE 是独立按键。

缺少当前截图属于执行前的观察不足，不能猜坐标，也不能重放原动作。统一入口拒绝整批副作用并为每个 callId 回传未执行结果，让模型重新观察和生成新指令；原生 computer 输出需要图片时通过既有截图能力返回当前图。此恢复只处理明确的执行前观察不足，不吞掉取消、安全检查、设备失败或部分执行异常。

无障碍平台事件只标记观察需要重新校验；不能将每个事件等同于页面语义变化。使用被事件标记的旧 ID 前，必须重新读取所选前台窗口，完整比较语义上下文、目标映射及边界，匹配后才续用同一观察身份。窗口切换、上下文变化、截断无法核对或显式操作失效仍拒绝，不能只校验按钮文字，也不能偷偷把旧 ID 绑定到新节点。

动态列表的语义定位是显式 `android_ui.click_match` 能力，不是放宽旧节点点击。调用保留原观察和原目标引用，并给出从该目标复制的稳定字面量 query；默认精确匹配，前缀匹配须显式选择并保留名称后的分隔符，禁止模糊、子串或正则猜测。执行端在同一前台窗口、同一可唯一识别的滚动容器里重新采集，按原目标种类、控件标识及 query 找到唯一可点击节点，再经过现有目标校验和 Android 节点动作。行号、路径、坐标和摘要变化不作为联系人身份；名称只是可见语义条件，不宣称等同于 QQ 账号 ID。

匹配必须在原观察和当前观察都唯一；目标缺失、同名、容器不明确、截断、保护节点或窗口变化时不执行。该能力不自动滚动、不跨窗口、不自动重试；需要滚动搜索时由模型显式调用现有 find，再重新选择。普通 `click` 继续使用严格快照契约。唯一执行入口负责预检、检查点、取消和记录，语义匹配器无独立设备执行权限。

叶子能力可在系统返回成功回执后同步通知只读的动作记录观察者，确保随后的取消不会抹掉已接受的输入。这不是任务完成回调：观察者不能改变生命周期、持有恢复逻辑、重试设备操作或提供新的执行策略。回执表示系统接受，不能冒充界面已验证。

## API 请求恢复边界

可继续聊天与可复用协议 cursor 是不同事实。失败或取消后可以保留同一会话身份和可见消息；普通发送通过已有显式文字上下文恢复路径继续，不能因此新建会话，也不能复用未完成的工具批次。新会话只能来自明确的新建操作。

`web_search` 与 `code_interpreter` 由 OpenAI 服务端执行。协议边界只读取其观察结果，不能把它们变成本地设备命令或伪造 function_call_output。服务端轨迹通过同一工具记录入口保存，云端 Python 不获得手机文件或设备权限；搜索来源链接须保持可见、可点击。

有限重试属于 Responses 网络客户端的一次请求，不属于任务重启或工具执行。每次重试保留同一序列化输入和 previous_response_id；只有完整成功解析的响应交给 runner，客户端没有调用设备、修改 cursor 或重放动作的权限。

瞬时连接故障、请求超时和可恢复的服务错误按类型化结果判断，最多在首次请求后重试三次。鉴权、参数、协议解析、证书校验以及额度/账单错误不靠重试掩盖。退避尊重服务端 Retry-After；超出有界等待预算时明确停止，不提前重发。

网络请求在退避期间仍保持单飞。协程取消、停止或改向导致的 client.cancel() 必须立即打断在途调用及退避，迟到响应不能进入新请求。重试诊断只包含脱敏的错误类别、状态、请求标识及次数，不记录认证头、请求正文、订阅或代理凭据。不得为了恢复网络另起任务 Job、状态机或 UI 恢复闭包。

## 可观察性与历史兼容

conversationId、runId、工具 callId、stepNumber 代表不同层级，不能混用。一段会话有多轮执行，一轮可以有多个模型步骤，一个步骤可以有多个工具调用。

历史列表按会话投影；时间线保留用户消息、Agent 可见输出、工具参数/结果、成功/失败/取消/跳过及耗时。不能把一个批次的工具名称概括当作全部日志。截图参数和结果中的 base64 不复制进文本日志；截断必须可见。

坐标标注来自本次真实完成的动作，画在模型使用的操作前图；操作后图独立呈现。文本/节点操作没有已捕获图时保持纯文本记录。标注动作数据和历史 Batch 不具有执行入口。

新字段向后兼容，旧 JSON、截图和既有标注继续可读。JSON null 不能变成字符串 `null`。不可恢复的信息明确缺失，不猜测旧坐标或编造操作结果。删除会话只处理所选会话；旧单轮 deep link 保留原单轮语义。

## 检查与验收

`ArchitectureContractTest` 检查核心依赖、UI 越权、旧执行器回流和不可变快照；其他测试验证生命周期、事件代次、命令负例、真实 JVM 管道/超时、键盘回执、嵌套租约、会话与日志兼容。

这些检查不是不可绕过的形式化证明。每次变更仍需检查真实调用链、拒绝路径、清理路径和测试覆盖。新功能若无法说明应该由哪一层拥有，先确定边界再实现。

标准验证目标：`:automation-core:test`、`:app:testDebugUnitTest`、`:app:assembleDebug`、`:app:lintDebug`。本机具体环境参数见独立验证报告和忽略目录下的构建脚本。

实机验证与自动化分开记录。安装必须保持包名、签名及用户数据；实际输入、截图恢复、人工交互、旋转/重建、服务重连和旧会话恢复，只有观察到才能记为通过。
